关于 Kanade

Kanade，一个记录热爱的小站。名字来自「奏」的读音，希望文字与代码也能像音符一样，组成属于自己的旋律。

小站使用 Astro、Vue 与 Tailwind CSS 构建。粉色、圆角、轻轻流动的波浪，是想留给每位访客的一点温柔。
