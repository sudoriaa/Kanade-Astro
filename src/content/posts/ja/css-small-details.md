## 余白から始める

カードが窮屈に見えるときは、内容の間隔を少し広げてみます。タイトルと概要を近くに置き、別の段落には十分な距離を取ると、情報の関係が伝わります。

余白は、読む順序やまとまりを示すためにも使えます。

## 影は少しだけ

淡い影はカードと背景の奥行きを表せます。テーマの色を少し混ぜ、透明度を高くすると、全体になじみやすくなります。

```css
.card {
  background: var(--card);
  border: 1px solid var(--line);
  border-radius: 18px;
  box-shadow: 0 5px 24px #88566a06;
}
```

境界線で輪郭を示し、影で距離を表すように役割を分けます。

## 動きは控えめにする

ホバー時に二ピクセル上へ動くだけでも、クリックできることは伝わります。短い動きにし、利用者の「視差効果を減らす」設定にも対応します。

```css
@media (prefers-reduced-motion: reduce) {
  html {
    scroll-behavior: auto;
  }
  .card {
    transition: none;
  }
}
```

## キーボードの現在位置を示す

キーボード操作ではフォーカスの輪郭が大切です。`:focus-visible` を使い、操作中の場所を見つけやすくします。

## 変数でテーマをつなぐ

背景、カード、文字、強調色を共通変数として定義します。テーマ変更時に変数を更新すれば、コンポーネント全体で色を合わせられます。

こうした小さな調整の積み重ねが、心地よい画面につながります。
