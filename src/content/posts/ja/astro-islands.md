## まず内容を HTML で届ける

ブログのタイトル、本文、日付、リンクは、多くの場合 HTML だけで表現できます。Astro はビルド時またはサーバー側でコンポーネントを描画し、その結果をブラウザに渡します。

Vue コンポーネントを読み込んだだけで、必ずその実行コードが送られるわけではありません。クライアントディレクティブがなければ、静的な HTML として出力できます。

## 一つのページに小さな島を置く

検索は入力に反応し、テーマボタンはクリックを処理します。記事本文は読むための内容です。操作する領域だけを個別に動かすのが、アイランドの使い方の一例です。

```astro
---
import Search from "../components/header/Search.vue";
import PersonalCard from "../components/home/PersonalCard.vue";
---

<Search posts={posts} client:load />
<PersonalCard posts={posts} />
```

検索はブラウザでハイドレーションされ、プロフィールカードは静的な内容を出力します。`posts` は周囲のページで用意するデータです。

## 読み込むタイミングを選ぶ

- `client:load`：ページ読み込み時に動かします。ナビゲーションや検索向けです。
- `client:idle`：ブラウザの待機時間に動かします。優先度の低い機能に向いています。
- `client:visible`：コンポーネントが画面に入った時点で動かします。

操作がなければ、静的なまま表示できます。

## データの境界も考える

クライアントコンポーネントに渡したデータは、ページの出力に含まれます。記事一覧に必要なタイトル、概要、タグ、リンクをまとめた要約を渡すと、送信する量を抑えられます。

要約の型を定義すると役割も明確になります。コレクションが内容を管理し、コンポーネントは表示に使う項目を受け取ります。

## JavaScript に役割を持たせる

静的な内容と部分的な操作は一緒に使えます。それぞれのスクリプトが何を担当するかをはっきりさせると、使いやすいページに近づきます。
